# Rainfall Analysis and Planting Advisory

## Project Summary
This project analyses monthly rainfall data from five Kenyan counties using Python and NumPy to identify rainfall patterns and recommended planting windows.

## How to Run
- Install the required libraries using `pip install -r requirements.txt`.
- Open `rainfall_analysis.ipynb` in Google Colab or Jupyter Notebook.
- Run all cells from top to bottom to generate the analysis and CSV summary.

## Planting Advisory
- Nairobi, Nakuru, Kisumu and Mombasa have April–May as their recommended planting window.
- Machakos has November–December as its recommended planting window.
- Farmers should consider local weather forecasts, soil moisture and crop requirements, noting that two Machakos readings were imputed.
